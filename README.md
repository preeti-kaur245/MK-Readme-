# 👋 Hey, I'm Manpreet

I'm a **BCA AI/ML student, product designer, developer and creative problem solver** who enjoys turning ideas into things that actually work.

I work across the space between:

**🎨 Design → 💻 Development → 🧠 Intelligence → ⚡ Automation**

I don't restrict myself to one technology or one type of project.

Sometimes I design a product.

Sometimes I build a website.

Sometimes I create a university system.

Sometimes I automate a boring workflow.

Sometimes I experiment with AI.

And sometimes I start with absolutely no idea how I'm going to build something — and figure it out along the way.

### My approach is simple:

> **Start with the problem. Build the solution. Use whatever technology makes the solution better.**

# 🧠 How I Build

I don't follow a fixed technology-first workflow.

I usually start here:

```text
             💡 IDEA
                │
                ▼
        🔎 WHAT'S THE PROBLEM?
                │
                ▼
          🧩 FIND THE FLOW
                │
                ▼
           🎨 DESIGN IT
                │
                ▼
           💻 BUILD IT
                │
                ▼
       ⚡ MAKE IT BETTER
                │
          ┌─────┴─────┐
          │           │
          ▼           ▼
       AUTOMATE       AI
          │           │
          └─────┬─────┘
                ▼
          🚀 REAL PRODUCT
```

### Technology comes after the problem.

If a simple solution works, I'll use it.

If AI makes it better, I'll use AI.

If automation removes unnecessary work, I'll automate it.

If something needs to be completely redesigned, I'll redesign it.

**The tool changes. The problem-solving mindset doesn't.**
